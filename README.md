# Tabia

A fantasy campaign setting, built for D&D-style play. This vault is the single source of truth for the world — geography, history, factions, peoples, NPCs, creatures, items, and the running log of actual play.

It's written in plain Markdown with relative links, so it works two ways:

- **As an [Obsidian](https://obsidian.md) vault** — point Obsidian at this `Tabia` folder and it opens straight away.
- **As a browsable wiki on GitHub** — every link below resolves to a real file, so GitHub's own file viewer renders it like a wiki with no extra tooling.

## Conventions

- **Links** — use standard relative Markdown links (`[Name](./Chapter.md)`), not `[[wikilinks]]`. Obsidian renders both; GitHub only renders the former.
- **Structure** — one chapter file per topic area, plus this index. New material goes in as a new section (`##`) within the relevant chapter, not a new file — unless a topic grows large enough to need its own chapter.
